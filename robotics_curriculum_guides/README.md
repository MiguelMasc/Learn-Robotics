# Robotics Curriculum Guides

Official robotics curriculum guides collected on 2026-08-06 from selected leading U.S. robotics programs, plus UC Santa Cruz.

The selection favors institutions with a clearly defined robotics degree, major, or certificate and a public official curriculum document. It is a comparison set, not a claim of formal ranking. Program requirements change, so use the linked official source as the final authority.

## Quick comparison

- Undergraduate degree maps: UCSC and WPI.
- Graduate program handbooks: Carnegie Mellon, Georgia Tech, and Michigan.
- Concise graduate requirement sheets: Penn, Johns Hopkins, and Oregon State.
- Cross-disciplinary undergraduate certificate model: Northwestern.
